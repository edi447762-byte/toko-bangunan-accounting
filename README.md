# 🏗️ Aplikasi Akuntansi Usaha Dagang Bahan Bangunan

Aplikasi akuntansi berbasis web untuk usaha dagang bahan bangunan, dibuat dengan **Streamlit**. 
Mencakup siklus akuntansi lengkap: penjualan, pembelian, jurnal, buku besar, neraca saldo, laba rugi, dan neraca.

## ✨ Fitur
- 📊 Dashboard interaktif (grafik penjualan & stok)
- 📦 Master Produk (CRUD)
- 🛒 Transaksi Penjualan (auto update stok + jurnal + HPP)
- 📥 Transaksi Pembelian (auto update stok + harga beli rata-rata + jurnal)
- 📝 Jurnal Umum (otomatis & manual)
- 📒 Buku Besar per akun
- ⚖️ Neraca Saldo
- 📈 Laporan Laba Rugi
- 🏦 Laporan Posisi Keuangan (Neraca)

## 🚀 Menjalankan Lokal
```bash
pip install -r requirements.txt
streamlit run app.py
